An installable extension of the supplied iML26-27 Exercise 1 starter. ## Definition

For M actual prediction trees and n reference examples:

```text
CSC = mean internal splits visited per tree and example
      + log2(1 + number of distinct split tests)
      + log2(number of distinct full-tree signatures)
```

Lower means less proposed structural complexity. Splits include feature position, operator, exact threshold and missing routing. Full trees include ordered topology, leaf outputs, output channels and effective scale. Classification leaves are normalized probabilities; boosting leaves are raw regression outputs. Constant leaf: CSC=0. Stump: CSC=2. Two exact duplicate stumps: CSC=2.

The score combines reference-dependent path occupancy with global model structure. The logarithms are heuristic proxies, not MDL code lengths. Equal weights do not imply empirically equal mental costs. Duplication can change boosting predictions while leaving CSC unchanged.

```python
from iml_interpretability import CognitiveStructuralComplexity
components = CognitiveStructuralComplexity().components(fitted_model, X_reference)
```

The existing scalar metric API and `evaluate()` remain usable. `RelativeNumberOfLeaves` is retained as a single-tree example. See [implementation details](docs/implementation.md) for compatibility and exact policies.

## Frozen experimental protocol

- Iris: 150 samples, 4 features, 3 classes. Breast cancer: 569 samples, 30 features, 2 classes.
- Seeds: 42, 1337, 2026. Stratified approximately 50/25/25 training/validation/test partitions; identical partitions for all configurations within each seed.
- Decision trees: depths 1, 2, 4, 8; min_samples_leaf=2.
- Random forests: 5 or 25 trees, depths 2 or 5; min_samples_leaf=2.
- Gradient boosting: 10 or 50 stages, depths 1 or 2; learning_rate=0.1. Multiclass Iris has three actual trees per stage.
- Twelve configurations per dataset/seed: 72 fitted models. Complete numeric features need no imputation or encoding.
- Select the smallest validation CSC within 0.02 absolute balanced accuracy of the best candidate. Break CSC ties by model name. Evaluate the already-fitted choice on untouched test data, without refitting: six final test rows.

## Hypothetical interpretability boundary

For each prediction, B(x) counts unique split tests encountered across all trees. R_b is the fraction with B(x)>b, for b=5,7,9. The declared operational boundary is R7>0.50. It is crossed by 42/72 validation configurations (58.3%). This is a design hypothesis, not an established human cognitive cutoff; CSC=7 has no special status. Aggregation effort is absent from B(x). Sensitivity results for R5 and R9 are in the CSV and budget plot.

## Checks and limitations

All 14 tests pass in the locked environment. They check hand calculations, duplicate invariance, changed outputs, missing routing, reference occupancy, multiclass channels, sklearn traversal agreement, budget deduplication, reproducibility and selection. Ruff checks and formatting were run using the available external ruff installation.

Supported inputs are dense numeric matrices in the fitted feature order. Custom boosting initializers and unsupported model families are explicitly rejected. Native missing routing is represented where sklearn supplies it. No XGBoost, human-subject study, cognitive calibration, formal prior-art novelty claim or optional meta-feature study is included. Few datasets, correlated components and representation sensitivity limit interpretation.

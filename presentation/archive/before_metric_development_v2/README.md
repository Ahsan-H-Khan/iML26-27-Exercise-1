# Cognitive-Structural Complexity: controlled comparisons

CSC measures structural complexity in fitted tree models. This extension implements stages 0–5 of the controlled-comparison strategy: exact controls, complete matched validation comparisons, per-example rule-demand measurements, plots and a revised five-minute presentation. The optional nested selector comparison was not run.

## Main findings

- **Q1: same size and function.** Two seven-node trees predict identically. Balanced CSC stays 4.00; chain CSC changes from 4.25 (uniform occupancy) to 3.30 (early exits) and 4.85 (deep exits). Node count misses this; TEPL also captures it.
- **Q2: same ensemble size.** Twelve stumps always have 36 nodes and TEPL 12. Increasing distinct stumps from 1 to 12 increases CSC from 2.00 to 8.29. Predictive functions may change in this diversity control. A separate equal-replication averaging control preserves predictions and CSC while raw size grows.
- **Q3: similar predictive performance.** All 396 same-dataset/seed pairs are retained. There are 218 accuracy-matched pairs, including 116 whose members are both near-best. Among the latter, CSC reverses node-count rankings only 3 times and TEPL rankings 7 times. This mostly confirms agreement, rather than superiority.
- **Budget repair.** Full exceedance curves and integer 90%/95% coverage budgets replace a universal seven-rule headline. All 78 original rows and six selections were reconstructed, with zero discrepancy at the stored numeric precision.

These are structural results. The real-data comparisons are exploratory, pairs are dependent, and no human comprehension or cognitive-capacity claim has been validated.

## Reproduce the extension

From this directory, install the locked environment and run:

```powershell
uv sync --extra dev
uv run pytest
uv run python scripts/run_controlled_comparisons.py
uv run python scripts/analyze_matched_performance.py
uv run python scripts/collect_reference_demands.py
uv run python scripts/plot_results.py
uv run python scripts/plot_controlled_results.py
```

These scripts take no arguments. The first creates deterministic fixtures; the second reads the original validation CSV and enumerates all within-group pairs; the third reconstructs original fits and refuses to publish demand tables if reconciliation fails. The last two regenerate figures from saved tables. New tables go to `results/controlled_v1/`; original plot refreshes go to `results/figures/`. Original `results/scores.csv` and `results/summary.json` are not rewritten. `scripts/run_experiment.py` remains the original baseline generator; it is not needed to reproduce this extension and would overwrite baseline results.

For the simplified audience-facing slides, first run `uv run python scripts/plot_plain_slides.py`. These charts use the unchanged controlled-v1 tables; the full research figures remain available. The earlier deck is preserved in `presentation/archive/controlled_v1_original/`.

Slide previews and notes are generated by `scripts/build_presentation.mjs` using the bundled artifact-tool runtime (or an installed `@oai/artifact-tool`). Set `CSC_ARTIFACT_MODULE` to its absolute module path if needed, then run `node scripts/build_presentation.mjs`. Run `python scripts/build_pdf.py` with reportlab installed to package the five previews as a PDF. This PDF uses high-resolution rendered slides; separate chart PDFs/SVGs remain vector assets.

## Metric and demand definitions

```text
CSC = mean internal splits per prediction tree and reference example
      + log2(1 + distinct split tests) + log2(distinct full trees)
B(x) = distinct split tests encountered across all trees for example x
L(x) = all split-node visits across all trees for example x
M    = number of actual prediction trees
R(b) = fraction of reference examples with B(x) > b
b_q  = smallest integer b covering at least fraction q of reference examples
```

The formula and canonical identity rules remain CSC 1.0. Fixture models use the same measurement and traversal implementation as fitted sklearn models. `CognitiveStructuralComplexity.reference_details(model, X)` exposes B, L and M; the existing scalar API remains compatible. Full tree identities include leaf outputs and output channels. CSC combines reference-dependent paths with global model structure; it is representation-dependent and its equal weights are not calibrated human effort.

B counts distinct tests, while L retains repeated execution and M exposes ensemble size. Output aggregation effort is still unmodeled. Budgets 5/7/9 and exceedance thresholds are available in `hypothetical_scenarios.csv` as sensitivity choices only. A CSC score of seven has no cutoff meaning.

## Scope

The preserved study uses Iris and Breast Cancer, seeds 42/1337/2026, 12 configurations per dataset/seed, and approximately stratified 50/25/25 train/validation/test splits. Selection minimizes validation CSC within two percentage points of the best validation balanced accuracy. Only the six frozen choices are evaluated on test data. New matching uses validation data only. Constructed controls and real-model evidence are reported separately. There is no new accuracy-improvement claim, metric reweighting, Task 2 implementation, GitHub submission or commit.
